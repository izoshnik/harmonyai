# HarmonyAI — правила для ассистента

## Версия приложения
Текущая версия показывается надписью «Beta X.Y.Z» в `app.html` (экраны входа и «О HarmonyAI»)
и в `package.json` → `version`. При КАЖДОМ обновлении, которое уходит пользователям, меняй обе:

- сейчас идёт серия 0.8.9x: каждое следующее обновление — +0.0.01 (0.8.92 → 0.8.93 → 0.8.94 …),
  независимо от размера;
- крупный апдейт (глобальное обновление) — 0.9.

Номер версии указывай в описании PR.

## Поддержка
Каналы поддержки — только ИИ-поддержка в приложении (`js/hm-support.js`, `/api/util?op=support`)
и почта harmonyaisent@gmail.com. Telegram-бота больше нет — не упоминай его.
