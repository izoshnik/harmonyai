# Performance strategy (K)

## Бюджеты (цели для замеров, уточняются на этапе 1)
| | Цель |
|---|---|
| Клиент (средняя целевая конфигурация — определить) | 60 FPS @1080p High |
| Сервер | тик 30 Гц при номинальном онлайне; far-симуляция ≤ 20% времени кадра |
| Память клиента | ≤ 12 ГБ RAM, VRAM по профилю качества |

## Мир
- World Partition + HLOD (3 слоя), Nanite для статических зданий/пропсов, ISM/HISM для повторяющихся элементов (окна, балконы, ограждения, деревья), Virtual Textures для фасадов.
- Модульные киты серий домов → высокая степень инстансинга при уникальных параметрах (Custom Primitive Data для цвета/износа без новых материалов).
- Интерьеры — только по входу (Level Instances), никогда не в общей сетке.
- Lumen: профили (Lumen HW RT / SW / выключен с baked-подобным освещением на низких) — настройка в меню Graphics.

## Симуляция
- AI LOD: near Actor / mid Mass / far event-driven (NPC.md). Лимиты near-сущностей на игрока и на сервер — параметры.
- Пулы акторов (NPC, машины, поезда, автобусы); никакого spawn/destroy в горячем пути.
- Async loading для всего, что материализуется (Soft references, Asset Manager bundles).
- Server streaming: сервер грузит только ячейки вокруг игроков/near-сущностей.

## Сеть
Replication Graph/Iris, частота по дистанции, dormancy, квантование (позиции поездов — пикетаж), relevancy по зонам (поверхность/подземка/интерьер).

## Контроль
Автоматические performance-тесты на фиксированных маршрутах камеры (Пионерская → Комендантский и т.п.) в CI, Unreal Insights-трейсы, регрессия по кадру/памяти — блокирует merge.
