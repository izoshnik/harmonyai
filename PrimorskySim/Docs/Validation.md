# World Validation (E)

Цель: ни один «реальный» объект не попадает в мир без записи и источника; любое расхождение видно в `WorldValidationReport`.

## Уровни

| Уровень | Где | Когда | Что проверяет | Статус |
|---|---|---|---|---|
| **L1 data** | `Tools/WorldPipeline/validate_world.py` (Python, без движка) | каждый коммит, CI | JSON Schema; уникальность ID; правила статусов (VERIFIED требует доказательств; непроверенное — `verification_needs`); существование источников; координаты в пределах СПб, перепутанные lat/lon; принадлежность границе для `district_scope=inside`; ссылки `related_ids`/`geometry_ref`; топология метро (линия ↔ станции) | **IMPLEMENTED**, 13 unit-тестов |
| **L2 import** | GIS-пайплайн (этап 2) | при импорте | связность дорожного графа (висячие узлы, изолированные компоненты); пересечения футпринтов зданий; здания на дорогах; маршруты ОТ проходят по графу; остановки у дороги; расхождения этажности OSM vs официальные данные | PLANNED |
| **L3 engine** | Commandlet `PrimWorldValidation` + Automation Tests (этап 2–3) | ночная сборка | каждый «реальный» актор имеет `object_id` из манифеста; нет акторов-«сирот» с реальными именами; navmesh покрывает тротуары/входы; станции метро и входы на своих местах (допуск в метрах); поезд проходит маршрут от тупика до тупика; автобус проходит весь маршрут; позиции не дрейфуют после повторного импорта | PLANNED |

## Отчёт

`WorldReference/Validation/WorldValidationReport.json|md`:
- `checks`: каждая проверка → `PASS | WARN | FAIL | BLOCKED`. **BLOCKED ≠ PASS**: проверка не выполнялась из-за отсутствия данных.
- `world_validated = true` только если нет ошибок, нет BLOCKED и все объекты VERIFIED. Пока это `false` — нельзя заявлять, что мир соответствует реальности.

## Расширение

Новая проверка = функция `check_*(objects, report)` в L1 или класс `UPrimWorldCheck` в L3 (регистрируется через подсистему, без правки общего кода). Каждая проверка обязана иметь unit-тест с положительным и отрицательным случаем.

## Запуск
```
pip install jsonschema
python3 Tools/WorldPipeline/validate_world.py
python3 -m unittest discover -s Tools/WorldPipeline/tests
```
