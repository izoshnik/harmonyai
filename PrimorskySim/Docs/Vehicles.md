# Vehicles, Traffic, наземный транспорт (I)

## Модель автомобиля (модуль PrimVehicles)
- Физика: Chaos Vehicles для near-LOD.
- `UVehicleDefinition` (Data Asset): масса, габариты, колёсная база, привод, мощность/крутящий момент (кривая), КПП, тормоза, подвеска, шины, расход, бак.
- Компоненты состояния (`UVehicleComponentState`): двигатель, трансмиссия, топливная система, тормоза, подвеска, шины (износ, давление, сцепление), электроника, кузов (зоны повреждений), пробег. Каждый имеет здоровье и эффект на параметры физики — это основа ремонта, диагностики, замены деталей, тюнинга (замена компонента = замена определения).
- Внешний вид: покраска (материальные параметры), обвес/диски как слоты.
- Модели из ТЗ: BMW M5 F90, Mercedes G63, Mercedes C200, Mercedes-AMG GT R, Volkswagen Polo, Kia Rio + массовый трафик. Реальные логотипы/названия — по `display_name_policy` (решение заказчика, юридическое).

## Дорожный граф (PrimTraffic)
- Строится из Roads-слоя: полосы с направлениями, связи полос на перекрёстках (turn lanes), стоп-линии, пешеходные переходы, светофорные объекты (фазы — данные; если реальные фазы неизвестны — `NEEDS_VERIFICATION` и типовой план), знаки (ограничения скорости, запреты), парковочные зоны.
- Один граф обслуживает легковые, автобусы, такси, спецслужбы, навигацию игрока (GPS) и far-оценку времени поездок.
- Трафик: mid/far — Mass (движение по полосам, IDM-модель следования, смена полос); near — Chaos Vehicle с AI-водителем; переход с сохранением скорости.
- Погода: коэффициент сцепления поверхности (сухо/мокро/снег/лёд) влияет и на Chaos, и на Mass-модель.

## Наземный общественный транспорт (PrimTransport)
- Источник: GTFS (маршруты, остановки, расписания). Трамвай — только там, где реально есть пути по данным 2026.
- `FTransitRoute`, `FTransitStop` (object_id манифеста), `FTransitTrip` (рейс) — данные; `UTransitDispatcherSubsystem` выпускает рейсы из парков/конечных по расписанию.
- Цикл: парк/конечная → остановки → посадка/высадка (NPC с задачей `Ride` + игроки) → конечная → следующий рейс. Отклонения от расписания — следствие трафика.
- Водитель автобуса как работа игрока: тот же рейс, но управление игроком; диспетчер учитывает отклонения.

## Спецтранспорт
Полиция, скорая, пожарные, коммунальные — те же машины + служебная роль (сирены, приоритет на перекрёстках, вызовы из соответствующих систем).

## Репликация
Машины near: server-auth physics, водитель-игрок с client prediction; трафик mid — прокси пачками; припаркованные машины — dormant.
