# Что нужно предоставить для максимально точной реконструкции Приморского района 2026

Куда класть: `WorldReference/<папка>/` (крупные файлы — в хранилище, о котором договоримся; в git — только индексы). Каждый присланный материал регистрируется в `Sources/SourceRegistry.json`.

## ОБЯЗАТЕЛЬНО

| # | Материал | Формат | Зачем | Как используется |
|---|---|---|---|---|
| 1 | **Доступ к OSM** — разрешить в настройках среды хосты `overpass-api.de` и `download.geofabrik.de`, **или** прислать выгрузку OSM Санкт-Петербурга не старше 2026 года (Geofabrik: Северо-Западный ФО, либо BBBike-экстракт СПб) | `.osm.pbf` | Базовая геометрия: граница, улицы, здания, POI, ж/д, метро-входы, остановки | GIS-пайплайн → слои GeoPackage → WorldManifest → импорт в UE |
| 2 | **Граница района**: результат `fetch_osm_boundary.py`, запущенного у вас, + ссылка на действующую редакцию закона СПб «О территориальном устройстве Санкт-Петербурга» (приложение с описанием границ) | `.geojson` + PDF/URL | Определение территории мира; без неё валидация `inside_boundary` = BLOCKED | Обрезка всех слоёв, стриминг, зоны симуляции |
| 3 | **Официальные данные по домам** района: этажность, год постройки, серия, назначение (открытые данные СПб / ГИС ЖКХ / «Реформа ЖКХ» — выгрузка по Приморскому району) | `.csv`/`.xlsx` с адресами | В OSM этажность заполнена не везде; выдумывать её нельзя | Слияние с футпринтами по адресу → `levels`, `series`, `year_built` |
| 4 | **GTFS наземного транспорта СПб** (актуальный на 2026) или ссылка на официальный фид | `.zip` (GTFS) | Реальные маршруты, остановки, интервалы автобусов/трамваев | `PrimTransport`: маршруты, рейсы, остановки → манифест |
| 5 | **Метро — официальные сведения на 2026**: схема, список станций района с действующими вестибюлями, линии эксплуатации «Балтийца» и составность | ссылки / PDF | Перевод станций и поезда из NEEDS_VERIFICATION | `PrimMetro` данные, манифест |
| 6 | **Фото «Балтийца»**: снаружи (бок, торец, сцепка), салон (сиденья, поручни, двери изнутри, межвагонный переход, табло/экраны, освещение), по возможности кабина; фото таблички с моделью вагона | `.jpg/.heic` оригиналы, 12+ Мп | Узнаваемая модель именно «Балтийца» | Референс для 3D-моделей, материалов, анимации дверей |
| 7 | **Фото станций метро района** (все 5 из списка): каждый вход снаружи, вестибюль, турникеты, эскалаторы (верх/низ), платформа с обоих торцов, путевая стена, табло | `.jpg` с EXIF GPS + время | Интерьеры и входы | Моделирование станций; проверка координат входов |
| 8 | **Рельеф**: Copernicus DEM GLO-30 (бесплатно) на район или точнее (если есть доступ к ЛиДАР/топосъёмке) | GeoTIFF | Насыпи, набережные, перепады у воды, мосты | Ландшафт UE, вертикальная привязка дорог |
| 9 | **Решения заказчика** (одним сообщением): версия UE (или «последняя стабильная»); VCS для контента — Perforce или Git LFS; размер населения (1:1 или коэффициент); стартовая ёмкость шарда; целевое «железо» игрока; политика брендов (реальные названия магазинов/авто/оружия/метро или нейтральные) | текст | Без этого нельзя начать этап 1 и выбрать бюджеты | PROJECT_STATE → архитектурные решения |
| 10 | **Где размещать игровой проект** — отдельный репозиторий (рекомендуется) или этот | текст | Этот репозиторий — веб-приложение HarmonyAI; UE-проект с гигабайтами контента в нём неуместен | Перенос `PrimorskySim/` |

| 17 | Референсы автомобилей из ТЗ (фото экстерьера/салона, тех. характеристики) | `.jpg`, `.pdf` | Модели машин и физика | `UVehicleDefinition` |

## Что НЕ присылать
- Скриншоты/выгрузки Яндекс Карт, Панорам, 2ГИС для «копирования» — их нельзя использовать как источник геометрии. Ссылку на точку Яндекс Карт присылать можно — для визуальной сверки.
- Фото, где различимы лица и номера автомашин, — по возможности нет (иначе они будут размываться перед хранением).
