# Production Roadmap (L)

Каждый этап имеет критерий выхода. «Готово» = собрано + проверено + отчёт валидации, не раньше.

| Этап | Содержание | Критерий выхода |
|---|---|---|
| **0. Основание** (текущий) | Архитектура, документация, схема манифеста, L1-валидация, пайплайн границы | ✅ документы, схема, L1 + тесты. ⛔ граница (нет доступа к OSM), решения заказчика (см. DataRequirements) |
| **1. Скелет проекта** | Source build UE, `.uproject`, модули из Architecture §3 (пустые интерфейсы + подсистемы), Client/Server/Editor targets, CI-сборка Win64, VCS для контента, нагрузочный стенд dedicated server | Чистая сборка всех target'ов в CI; пустой мир поднимается на dedicated server, 2+ клиента подключаются |
| **2. Данные мира** | Граница (VERIFIED/PARTIALLY), OSM-выгрузка 2026, официальные данные зданий, GTFS, DEM; L2-валидация; commandlet `ImportWorld`; локальная проекция и origin | Дорожный граф района связен; все здания района в манифесте; L2 без ошибок |
| **3. Мир в движке (black-box)** | Рельеф, дороги, тротуары, футпринты/массы зданий с реальной этажностью, World Partition сетки, HLOD | L3: каждое здание ↔ manifest; навигация пешехода/машины по всему району |
| **4. Метро** | Станции района (после верификации), трасса, `Балтиец`, диспетчер, посадка/высадка, пассажиропоток | Игрок проезжает между всеми станциями района в мультиплеере; L3 метро без ошибок |
| **5. Ядро геймплея** | Interaction, персонаж, инвентарь, экономика/Ledger, persistence | Сохранение/загрузка игрока; покупка через Ledger; анти-чит тесты экономики |
| **6. Симуляция города** | NPC (far/mid/near), расписания, трафик, наземный ОТ, день/ночь, погода | 24 ч игрового времени без деградации тика; NPC доезжают на работу через ОТ/метро |
| **7. Системы** | Работа, полиция/закон, транспорт (полная модель, ремонт/тюнинг), оружие/бой, травмы, разрушения, недвижимость/строительство, диалоги LLM/голос | Сквозные сценарии из ТЗ (доставка, вызов полиции после выстрела) проходят без скриптов |
| **8. Детализация мира** | Фасады по фото, дворы, POI, интерьеры по приоритету, знаки/разметка/светофоры | Доля VERIFIED по критическим/высоким объектам ≥ целевого порога (утверждается) |
| **9. Production polish** | Настройки, доступность, локализация, оптимизация, анти-чит, бэкенд в проде | Performance-бюджеты выполнены; нагрузочный тест шарда |

Параллельно с этапа 2: сбор фото по приоритетным маршрутам (DataRequirements), верификация объектов.
