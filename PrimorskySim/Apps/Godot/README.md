# Приморский 2026 (Godot 4.5, Windows)

Открытый мир на реальных данных Приморского района (OpenStreetMap, 07.10.2026). Собирается в один `Primorsky2026.exe`.

## Управление
| Клавиша | Действие |
|---|---|
| W A S D, мышь | ходьба, обзор (клик — захватить мышь, Esc — отпустить) |
| Shift / Пробел | бег / прыжок |
| F | полёт (E/Q — вверх/вниз, Shift — быстрее) |
| T | скорость времени ×1 / ×60 / ×600 |
| 1 / 2 / 3 | качество графики: низкое / среднее / высокое (SDFGI) |
| H | показать здания, высота которых не подтверждена данными |
| F1 | подсказка, F11 — полноэкранный режим |

## Что в мире и откуда
- **Реальные данные OSM:** граница района, 12 968 зданий (контуры, этажность — там, где она есть), улицы с шириной по числу полос, тротуары, вода (включая мультиполигоны), парки и леса, 4 595 отдельных деревьев, 1 294 фонаря, станции метро.
- **Условные (не из данных):** высота зданий без этажности в OSM (клавиша H показывает их), расположение деревьев внутри парков и лесов, фонари вдоль магистралей с шагом 40 м, маршруты машин (случайные по реальному графу дорог).
- **Ассеты:** текстуры ambientCG (CC0), фонарь и дерево Poly Haven (CC0; дерево — импостор, отрендеренный из исходной фотограмметрии), машины — процедурные модели `Art/Tools/build_cars.py`, фасады панельных домов — процедурный шейдер.

## Сборка
```
# импорт ресурсов и экспорт Windows-сборки (Godot 4.5 + export templates)
godot --headless --path Apps/Godot --import
godot --headless --path Apps/Godot --export-release "Windows Desktop" ../../Build/Windows/Primorsky2026.exe
```
Данные обновляются: `Tools/WorldPipeline/import_osm.py` → `export_web.py` → скопировать `Apps/Web/data/district.json` в `Apps/Godot/data/`.
